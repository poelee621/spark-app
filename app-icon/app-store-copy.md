## 描述
闪写 Spark 是专为中文内容创作者打造的灵感助手。

输入一个主题，选择你要发布的平台（公众号 / 小红书 / 短视频）和想要的文风，一键生成标题、内容提纲、正文和金句。无论是热点评论、产品种草还是剧情脚本，都能快速出稿。

核心功能：
• 多平台适配：公众号长文、小红书笔记、短视频脚本，一键切换
• 多种文风：犀利质疑、温情走心、干货实操、悬念反转
• AI 大模型 + 规则引擎双驱动：可配置 DeepSeek / OpenAI 等 API Key，未配置时自动降级规则引擎
• 一键复制：标题、正文、金句单独复制，直接粘贴发布
• Pro 会员：无限生成、高级模板、爆款标题库、Markdown 导出

适合自媒体人、运营、文案、博主和任何想快速把灵感变成内容的人。
