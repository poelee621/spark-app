# 闪写 Spark · App Store 预览视频脚本（15 秒）

> 用途：在 iOS 模拟器（或真机）录屏后，剪出 15 秒预览视频，上传 App Store「应用预览」。
> 风格：快节奏、字幕大字、蓝紫品牌色。背景音乐用轻快无版权曲。
> 录制方式：`npx cap open ios` → 模拟器 Run → 菜单 Window → Record Video。

## 拍摄要点
- 全程竖屏（iPhone 6.7"），分辨率 1920×1080 或 1290×2796。
- 前 3 秒必须出现核心功能（App Store 预览规则：前几秒决定留存）。
- 字幕用白色粗体 + 半透明黑底，保证浅色背景下可读。
- 不出现真实付费价格以外的促销文字，避免审核风险。
- 结尾尾板留 0.5s 静止，方便加「下载」引导。

## 成片交付
- 文件：`spark_preview_15s.mov`（或 .mp4，H.264，≤ 256MB）。
- 位置：与截图一并放入 `assets/`，上传 App Store Connect。
- 进度：⏳ 待模拟器录屏（卡坡哥的 Apple Developer + macOS/Xcode）。
