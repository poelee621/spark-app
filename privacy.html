隐私政策

闪写 Spark（中文创作灵感助手）· 最近更新：2026-08-19
一句话总结：我们不收集你的真实身份，不卖你的数据，你的创作内容只用于给你生成结果。

1. 我们收集什么

闪写 Spark 不要求注册账号，因此默认不收集姓名、手机号、邮箱、地理位置等个人身份信息。我们仅在以下情况接触数据：

  • 你输入的主题 / 关键词：用于在你设备或你配置的 AI 服务商处生成内容。
  • 订阅状态：由 Apple / RevenueCat 处理，用于解锁 Pro 会员功能。
  • 你主动填写的 AI 服务商 API Key：仅保存在你本机（浏览器/应用本地存储），我们服务器不接收、不存储。

2. 创作内容如何处理

在规则引擎模式下，所有生成完全在你的设备本地完成，不上传任何服务器。

在大模型（AI）模式下，你输入的主题会与你的 API Key 一并发送给你所选择的服务商（DeepSeek / 通义千问 / 智谱 GLM / OpenAI）。我们作为应用本身不中转、不留存这些请求内容。

3. 订阅与支付

会员订阅通过 Apple App Store 内购（由 RevenueCat 协助）完成。支付由 Apple 直接处理，我们无法获取也不会存储你的信用卡号、Apple ID 密码等支付凭证。订阅记录由 Apple / RevenueCat 管理，你可随时在系统「设置 → Apple ID → 订阅」中查看或取消。

4. 数据共享与出售

我们不会向任何第三方出售你的个人信息或创作内容。除为完成上述生成/订阅所必需（即你选择的服务商与支付渠道）外，不与第三方共享。

5. 你的权利

  • 随时清除本机保存的 AI Key（App 内「AI」页 → 清除 Key）。
  • 随时取消订阅（Apple 系统设置内操作）。
  • 对本政策有任何疑问，可联系我们删除相关本地数据。

6. 儿童隐私

本应用分级为 4+，不面向儿童收集信息，不含不良内容。
